# Updates on Oliver et al. (2018)
This repo stores the code and supporting data supports the updates of Oliver et al. (2018). It includes:
## Codes
`Figure1-3.m` Codes to generate main Figure in the submission
`MHW_reconstruct.m` Reconstruct MHWs using the monthly proxy and GLM.

## Data
`MHW_ice_slopes_colored.xlsx` MHW trend data for each ecoregion. For each ecoregion, it inlcudes its belonging realms, trends estimated during 1982-2025 for frequency, maximum intensity, duration, annual MHW days, and annual cumulative intensity, and the proportion of ice covered area.
